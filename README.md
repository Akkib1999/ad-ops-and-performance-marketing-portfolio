# 📊 Automated Ad Ops System Health Portal

A live, high-performance Ad Ops Infrastructure Diagnostic Portal designed to prevent multi-channel budget leaks and track real-time pipeline telemetry across **Meta, Google, and TikTok**.

🔗 **[Live Interactive Dashboard Link](https://google.com)**

---

## 🛑 The Problem: Silent Operational Killers
In high-budget digital operations, structural failures cost immediate revenue. Tracking pixels drop out unnoticed, or ad network delivery algorithms overspend by 25%—with performance teams often failing to catch the anomaly for up to 48 hours. This data fragmentation results in direct, unrecoverable revenue loss.

## 💡 The Solution
To solve this data friction, I engineered a live **Ad Ops Infrastructure Diagnostic Portal in Looker Studio**, powered by a unified cross-channel simulated data pipeline. This setup replaces reactive manual auditing with automated structural safety guardrails.

## ⚙️ Core Automation Features

* **🚨 Critical Overspend Tracker:** Employs dynamic calculated monitoring logic (`CASE WHEN`) to immediately flag campaigns pacing **>10% over daily thresholds** by instantly highlighting rows in bright red.
* **🟠 Tracking Discrepancy Audits:** Computes real-time variance between ad network metrics and internal merchant databases to instantly surface server-side pixel drops (**>5% margin gaps**).
* **🎛️ Birds-Eye Executive Triage Blocks:** Consolidates active pipeline failures (such as *Disapproved Campaigns* and *Failed Tracking Scripts*) into single-screen summary counters for immediate operational triage.
